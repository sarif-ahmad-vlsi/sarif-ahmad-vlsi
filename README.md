# TCAD Simulation & PVT Reliability Analysis of Double-Gate TFETs

## 🚀 Key Features & Results
- **Device Simulator:** Silvaco ATLAS (DeckBuild / TonyPlot)
- **Primary Mechanism:** Quantum Band-to-Band Tunneling (BTBT)
- **Evaluated Metrics:** $I_{\text{ON}}$, $I_{\text{OFF}}$, $I_{\text{ON}}/I_{\text{OFF}}$, $V_{\text{T}}$, Point SS, Average SS

### 🔍 Simulated Effects:
1. **Process Variations:** Gate misalignment ($\pm 15\text{ nm}$), oxide thickness scaling ($t_{\text{ox}} = 3\text{ nm}-5\text{ nm}$), interface fixed charge density ($Si\text{-}SiO_2$), and metal work function engineering ($3.9\text{ eV}-5.2\text{ eV}$).
2. **Thermal Stability:** Temperature sweep ($298\text{ K}$ to $448\text{ K}$) demonstrating weak subthreshold swing temperature dependence compared to MOSFETs.
3. **Voltage & Doping Scaling:** Transfer ($I_{\text{DS}}\text{-}V_{\text{GS}}$) and output ($I_{\text{DS}}\text{-}V_{\text{DS}}$) characteristic analysis under scaled $V_{\text{DD}}$ supply voltages.
